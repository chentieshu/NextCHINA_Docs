# NextCHINA：文档即数字花园的统一工作区

## 决策与范围

不再在“文档网站”和“数字花园”之间跳转。以 Obsidian 的文件浏览与工作区心智模型重新组织 UX：左侧选择全部文档，中间阅读，图谱是同一工作区的另一种视图。不是复刻 Obsidian 编辑器，也不添加本地文件系统权限。

参考：
- https://obsidian.md/help/workspace
- https://obsidian.md/help/plugins/file-explorer
- https://obsidian.md/help/tabs

只读静态 MD/JSON 架构、所有正文、概念 ID、文章 ID、来源快照和价格记录保留。本轮不重新核验排行榜、不改写知识正文或扩充模型数据。

## 新的交互契约

- `/` 直接进入工作区并打开已有阅读指南。删除独立营销式首页和“进入文档/进入花园/在阅读器打开/返回花园”的跨页面流程。
- 同一个侧栏持续挂载。目录展开与当前阅读文档独立；显示当前文档位置，可以折叠所有目录、定位当前文档。
- 目录由已启用专题、递归分支与显式资源引用派生；每篇公开文档都必须可以选择。跨专题引用有多个导航位置，但正文只有一个 ID。
- 默认隐藏没有已写资源的规划分支，可开启“显示待完善大纲”。空分支是目录，不生成假文档。LLM 十二主分支及所有深层计划仍保留。
- 文档标签按规范文章 ID 去重。目录钻取复用一个目录标签，而非每展开一级就新增标签。会话保存最近 24 个标签；URL 优先于会话，不覆盖深链接。标签可关闭，不实现拖拽分屏和编辑器。
- 全库搜索在侧栏进行，检索标题、标签与实际正文，标题匹配优先。选择后回到目录并揭示所选位置。Ctrl/Cmd+K 打开搜索，Ctrl/Cmd+反斜杠切换侧栏。
- 右侧“关联资料”默认关闭，分开列出收录位置、正文链接和引用当前文档的链接。目前识别站内查询参数形式的内联 Markdown 文档链接，不声称实现完整 Obsidian wikilink/块引用体系。没有复活本文标题目录大纲，不把目录共现当正文反向链接。
- 关系图在主区域的标签中打开，不替换侧栏或主题。全库图展示现有文档与主要专题收录关系；局部图展示当前主题、子节点、共享概念及实际文档。点击文档节点直接阅读；布局失败可用目录继续。

## 路由兼容

保留 `?view=article&article=...` 与 `?view=garden&scope=...`。旧专题叶子带 embeddedArticleId 时转换到规范文章路由，并保留该分支作为目录上下文。旧的 node 选择链接进入相应知识对象。返回目标仍由原 safeGardenReturn 验证，仅允许本地 garden 参数。

内部 Markdown 文档链接通过统一导航处理；外站、下载、新窗口与本页片段遵循原链接行为。浏览器后退、前进与刷新仍有效。阅读滚动位置在当前应用实例内按标签保留；会话恢复标签不等于跨设备同步。

## 布局计算和滚动归属

桌面：44px 工具条 + 288px 文档侧栏 + 可用主区；关闭侧栏时其轨道为 0。1280px 及以上可额外展开 264px 关联资料栏。正文最大阅读宽度 820px，侧栏展开不会增大整页宽度。

- 1440px，侧栏与关联资料同时打开：主区 = 1440 - 44 - 288 - 264 = 844px，再扣正文内边距。
- 1024px，侧栏打开：主区 = 1024 - 44 - 288 = 692px；关联资料使用覆盖面板。
- 小于 960px，工具条隐藏、侧栏默认关闭。抽屉宽 min(340px,视口-40px)，主区宽不变。
- 390px：主区390px；正文左右各16px，剩余358px，另需考虑设备实际滚动槽。抽屉关闭后不占正文宽度。

workspace 独占 100dvh；主区由标签栏、面包屑/视图栏、minmax(0,1fr) 内容、状态栏组成。目录、正文、关联资料分别滚动；body 不滚动。表格/公式/代码局部横滑，画布只在图谱内部平移。

移动抽屉与窄屏关联资料互斥，使用 inert、Escape、Tab 约束与恢复焦点。打开抽屉不再给正文增加 margin-left，也不使用 body fixed/top 的两套锁定策略。顶部/底部安全区由贴边工具栏和状态栏负责。

## 模块职责

- Workspace.tsx：唯一外壳、路由、抽屉、标签、阅读位置、内部链接。
- model.ts：目录 occurrence、规范文档引用、路由上下文、正文链接、文档/局部图投影。
- Explorer.tsx：递归目录、键盘导航、搜索、显示规划分支、定位。
- Content.tsx：复用 MarkdownRenderer 的唯一正文入口、目录索引、关联资料。
- useWorkspace.ts：可关闭标签、受限存储回退、模态焦点和主题。
- WorkspaceGraph.tsx：按需加载现有 React Flow + ELK，只负责主区域图谱。

删除旧 DocsHome、DocHeader、Sidebar、SpaceSelector、SearchModal、GardenPage、NodeInspector、TopicHubView、HubOutlineNav、GardenList 等独立壳层。历史设计文档保留作为版本背景，本文件是新的 UX 契约。保留 Markdown/图表渲染器与静态数据测试。
