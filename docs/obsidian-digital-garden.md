# NextCHINA · Obsidian 风格数字花园

## 界面目标

本契约替代六区卡片式地图，不改变现有知识定义和资料来源。不是给原卡片换皮，也不是复制 Obsidian 编辑器的全部功能。

设计参考为 Obsidian 的 Graph view 与 Backlinks 交互语言；本项目的点仍代表规范知识对象，不把目录归属或专题引用伪装成正文链接。

## 工作区

44px 工具侧栏 + 254px 文件树 + 尽可能完整的点线图 / 单文档阅读区。深灰、低饱和灰线、紫色选中态；明亮主题保持同一结构。尊重已有明暗选择，未设置时默认为暗色。

没有应用 titlebar、多文件标签、卡片区域、巨型首页标题或默认占位的说明栏。仅保留图谱自己的紧凑工具行和按需打开的知识笔记面板。左侧文件夹点击只展开/收起，不突然把主区域替换成目录页；文档点击才打开阅读器。

## 一张网络

使用现有 graph.nodes 与 graph.edges。布局不新增语义边，不从学习路径制造先修关系，不复制文章或概念。所有规范知识节点均可搜索，根与虚拟导航记录不作为可见知识点。

目录结构以更淡连线呈现；已记录的知识关联和建议先学关系可分别识别。原始方向和理由仍在知识索引中查看。可按需关闭结构连线、隐藏无资料节点、调整标签密度或使用现有区域分组着色。

力导向布局只为读取生成坐标。使用确定性初始种子、有限迭代、短任务分片和取消信号；布局计算不会因点击、缩放或筛选重启。数据不依赖视觉坐标。

## 操作闭环

悬停：高亮当前节点的一跳关联。点击：打开知识笔记；从笔记中的明确资料入口进入原阅读器。空白处点击或画布 Escape：关闭选择。搜索定位：恢复被筛选掉的目标，不重新生成另一张图。

支持鼠标拖动平移、滚轮以指针为中心缩放、双指缩放、方向键平移、加减号缩放、0 显示全图。标签按屏幕空间避让，字号不随整个图缩小；小屏保留可读的主要标签。

选择由现有 GardenRoute.nodeId 保存。原安全 return 路由和正文继续阅读逻辑保留；返回图时恢复原知识对象。视口仅为辅助状态，内存/会话存储不可用时不影响阅读。

右侧知识笔记展示规范位置、下级、双向关系、专题引用/被引用、学习路径、资料及内容状态。继续使用 knowledgeIndex，不将有资料等同于独立讲解完成。

## 模块

- networkEngine.js：原生 SVG、确定性布局、相机、鼠标/触摸/键盘和屏幕空间标签。
- ObsidianCanvas.tsx：React 生命周期与渲染器适配。只在数据集变化时挂载，在卸载时取消事件、布局与观察器。
- WorkspaceGraph.tsx：保留真实 NodeDetails 和关系索引，替换卡片首页的默认组件为点线工作区。
- obsidian.css：只作用于 workspace / og / kg 命名空间。旧 AtlasMap 文件不再由首页引用。
