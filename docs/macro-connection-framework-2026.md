> 状态：设计草案，不是已完成百科，也不是对仓库内榜单/报价的重新核验。
> 调研窗口：公开资料截至 2026-09-29。Stanford AI Index 2026 多数技术与投资数字停在 2025 全年至 2026 年 3 月；协议与世界模型进展补到 2026 年 9 月。
> 原则：主题产生分支；学科知识通过带类型的边连通；空节点允许存在，但不生成假文章。

## 0. 调研结论：2026 年改变了什么

旧框架如果仍以「一篇 LLM 总览 + 产品目录 + 三张榜」为中心，会漏掉 2025–2026 已经变成一等公民的几条轴。

### 必须写进骨架的事实（高等级来源）

1. **能力在加速，但形状是锯齿状的。** Stanford HAI *2026 AI Index*：SWE-bench Verified 一年内从约 60% 到接近 100%；同一批模型可在奥赛级数学上拿金牌，模拟时钟正确率约 50%。能力不能在任务之间任意迁移。
2. **竞争从“谁分最高”变成“成本、可靠、专用”。** Index：2026-03 Arena 第一梯队挤在约 25 Elo 内；美中领先幅度约 2.7%。开放权重与闭源差距在 2025 重新拉开。名称相近 ≠ 同一版本。
3. **训练缩放之外，推理时计算成为独立维度。** 2025 起的 reasoning / test-time scaling 把“同一模型 + 不同推理预算”变成不同评测对象。深度（加长一条思路）、宽度（多样本）、反馈（验证后再试）不是同一种计算。
4. **生成骨干收敛，但目标函数分裂。** 文本主流仍是自回归 Transformer + MoE；长上下文出现 SSM / Gated DeltaNet 混合。图像/视频主流是 DiT + Flow Matching，并出现 AR 规划 + Flow 渲染的混合。U-Net 已退出前沿主路径。
5. **世界模型、VLA、视频生成必须拆开。** 2026 年产业与综述已明确三类：世界基础模型（预测/仿真环境）、VLA（视觉-语言-动作）、可交互生成世界（像素级可玩仿真）。不能把 Sora 系视频生成写成机器人世界模型。
6. **Agent 能力上升，组织内部署仍低。** OSWorld 类电脑任务从约 12% 到约 66%；家庭机器人真实家务成功率约 12%。组织 AI 采用率约 88%，但业务函数里的 Agent 部署仍是个位数。能力榜 ≠ 生产采用。
7. **接口层已经标准化。** MCP（模型↔工具）与 A2A（智能体↔智能体）在 Linux Foundation / AAIF 下分工；MCP 有跨厂商客户端，A2A 在 2026 进入 v1.0。系统专题必须把协议当实体，而不是脚注。
8. **评测与治理落后于能力。** 基准迅速饱和；前沿模型透明度下降；记录在案的 AI 事件 2025 年 362 起。NIST 2026-09 的 ARIA 把评测拆成模型测试 + 红队 + 用户测试。Measure 与榜单快照不是同一件事。
9. **算力、能源、供应链是约束，不是背景。** Index：全球 AI 算力自 2022 年起约每年 3.3×；美国数据中心数量与能耗突出；先进芯片高度依赖单一晶圆厂。成本、时延、能耗必须能连回推理系统和治理。

## 1. 设计判断

现有 14 领域可以保留为覆盖地图，不必改成大学院系目录。要改的是联系方式：

- 侧栏继续：主题中心 → 问题分支 → 共享概念 / 文章。
- 知识层新增：一张跨领域的**类型化关系图**。主题是入口，边才是“整体联系”。
- 0→1 是先修/依赖边生成的路径，不是把全部学科先铺成空文件夹。

2026 年新增的“必须能走通”的主链：

```text
数学与学习目标
  → 表示与架构（Transformer / SSM / MoE / DiT）
    → 训练 + 后训练 + 可验证奖励
      → 推理时计算 / Prefill-Decode / KV
        → 模态系统（语言、视觉、语音、视频、3D）
          → 检索与记忆（Embedding / RAG）
            → 工具与协议（MCP）+ 多智能体（A2A）
              → 世界模型 / VLA / 控制（物理智能，与视频生成分叉）
                → 评测协议（任务×预算×工具×版本）
                  → 产品与总成本
                    → 风险、权利、能源、政策
```

## 2. 实体类型

避免把“ChatGPT”“Transformer”“SWE-bench 某次分数”画成同类圆点。

| 类型 | 例子 | 说明 |
| --- | --- | --- |
| DisciplineConcept | 条件概率、梯度、信息瓶颈 | 学科概念，可被多主题引用 |
| Mechanism | 自注意力、RoPE、Flow Matching、GRPO | 可指明输入/输出/假设 |
| ArchitectureFamily | Transformer、SSM、DiT、混合注意力-SSM | 家族，不是一个检查点 |
| LearningObjective | 下一 token、去噪、流匹配、对比学习、RL 回报 | 同一骨架可换目标 |
| ModelVersion | 某一已披露检查点 | 禁止用产品营销名合并 |
| SystemPattern | RAG、Agent loop、工作流、MCP 宿主 | 模式 ≠ 产品 |
| Protocol | MCP、A2A | 接口实体 |
| EvaluationProtocol | 任务 + 拆分 + 工具 + 推理预算 + 判分 | 评测对象是系统+配置 |
| BenchmarkSnapshot | 仓库内 Arena / AA / Terminal-Bench | 有日期的快照 |
| ProductOffer | SaaS 套餐、API 报价 | 报价 ≠ 模型能力 |
| RiskControl | 提示注入、越权、深伪、能源核算 | 风险与缓解分开 |
| ApplicationTask | 代码修复、临床文书、工业分拣 | 任务有非 AI 基线 |

文章、教程、微观算例是这些节点上的**资料绑定**，不是第四套分类树。

## 3. 边类型

浏览树继续用 `browse_child`。科学/工程联系只用下表。`related` 降为待审核的阅读提示。

| 边 | 含义 | 2026 年为什么必要 |
| --- | --- | --- |
| requires | 读/实现 B 需要 A | 0→1 路径 |
| part_of | 部件→整体 | 防止每个模态复制一套 Transformer |
| uses | 系统→机制/模型 | 组合关系 |
| trained_with | 模型→目标/数据/算法 | 骨架相同、目标不同 |
| served_as | 模型→推理体制 | 预算是一等参数 |
| evaluated_by | 主体→协议/快照 | 禁止混榜 |
| deployed_as | 模型→产品 | 模型≠产品 |
| constrained_by | 系统→资源 | 工程与治理接通 |
| risks | 系统→危害 | 关联不是“已消除” |
| mitigates | 控制→危害 | 不得写成 eliminates |
| contrasts_with | 容易混淆的对 | 世界模型 vs 视频生成 |
| not_evidence_for | 否定传染 | Agent 分 ≠ 裸模型能力 |

每条边必须带：`assertionStatus`、`scope`、`asOf`。

## 4. 七条宏观脊梁

### R1 表示：数学 → 机制

`向量/张量 → 点积/矩阵乘 → Softmax → 注意力 → 残差与归一化 → 位置机制`

### R2 目标：同一计算，不同损失

`监督 / 自监督 / 对比 / 下一 token / 去噪或流匹配 / RL / 偏好优化`

### R3 架构：2026 主路径

```text
稠密 Transformer
  ├─ MoE
  ├─ 线性/稀疏注意力、GQA/MQA
  ├─ SSM / DeltaNet 混合
  └─ DiT
        └─ AR 规划 + Flow 渲染
```

### R4 运行：训练一次，推理多次

```text
数据 → 训练 → 后训练
  → Prefill / Decode → KV / 批处理 / 量化
  → 推理时计算（深度 / 宽度 / 反馈）
  → 任务总成本
```

### R5 系统：模型 → 可执行工作

```text
检索 → RAG → MCP 工具 → 规划/权限/沙箱 → A2A → 人工确认
```

### R6 物理智能（与视频生成分叉）

```text
观测 / POMDP → 世界基础模型 → VLA / 策略 → Sim-to-Real → 物理安全
```

### R7 证据与约束

```text
任务质量 / 校准 / 安全 → 评测协议 → 快照分开
  → 产品适用性 → 权利与法域 → 算力、电力、事件
```

---

## 5. 禁止合并的节点对

基础模型 ≠ 聊天产品；模型版本 ≠ 推理预算；Transformer ≠ DiT；Token Embedding ≠ 检索 Embedding；RAG ≠ 微调；Agent 成绩 ≠ 裸模型能力；视频生成 ≠ 世界模型 ≠ VLA；MCP ≠ A2A；API 单价 ≠ 任务总成本；人类偏好榜 ≠ 综合指数；开源权重 ≠ 可商用许可。
