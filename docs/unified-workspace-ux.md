# NextCHINA：统一学习工作区 UX

本文件与 [宏观知识地图设计](macro-knowledge-map-redesign.md) 是现行交互契约。之前的“多文档标签、首页阅读指南、按页面生成局部图”方案已被替换，不应作为后续实现依据。

## 产品边界

整个产品是一个只读学习工作区，而不是编辑器。复用静态 MD/JSON、现有正文、规范概念 ID、文章 ID、来源快照和价格记录。界面重构不代表重新核验榜单或新增知识事实。

全站只有一张宏观知识地图。概念只定义一次，专题和文章引用它。地图负责理解结构与关联，文档负责展开解释；不为文章创建一张新的图。

## 页面结构

桌面是工具条、文档侧栏、主内容区。没有 titlebar 和多文档标签。手机使用底部工具栏和可关闭文档抽屉。文档侧栏始终使用同一套目录状态和搜索逻辑，不因在地图与阅读之间切换而换一套导航。

`/` 默认打开宏观知识地图。主内容区可切换为单篇文档阅读或真实目录索引。阅读指南是一篇普通的可访问文档，不冒充宏观地图或每个空概念的讲解。

## 地图与知识详情

六个区域从 blueprint 的 groups 派生，领域和专题复用规范节点。区域位置服务于阅读，不代表科学距离或先修顺序。点击领域、专题、搜索结果或关系另一端，只选择规范节点，不重排或重新挂载地图。

详情包含知识位置、下级知识、原始直接关系及两端、专题引用与被复用、资料来源和学习路径。完整关系索引可以筛选和逐批显示，每条原始关系保留 ID 和说明。

区域跨区连线是原始关系的汇总包，不丢弃同一组内其他关系。手机窄屏可隐藏装饰连线，但必须保留区域关系入口与完整索引。

桌面详情区固定占位，选择前后地图宽度不变化。窄屏详情覆盖地图并约束焦点，Escape 和关闭按钮可退出。地图不同时打开文档模式的第二个“关联资料”面板。

## 文档与侧栏

文档只有一份正文，可以在多个专题目录中出现引用位置。已发布文档必须在侧栏或搜索中可达。规划分支是目录，不生成假文档；可切换显示待完善大纲。

全文搜索检索标题、标签与正文，标题匹配优先；选择后显示当前文档位置。Ctrl/Cmd+K 打开侧栏搜索，Ctrl/Cmd+反斜杠切换侧栏。目录保留折叠、定位与键盘访问能力。

文档模式的“关联资料”分别列出收录位置、已识别正文链接、反向文档引用，不把目录共现当成正文反向链接，不声称实现完整 wikilink 或块引用体系。

## 路由与闭环

保留 `?view=article&article=...` 与 `?view=garden&scope=...`。图谱路由统一为 scope=root:ai，并通过 node 参数恢复选择。旧局部图链接转换到这张全局地图，保留可识别的节点上下文。

从地图打开资料时，文章 return 参数保留安全的原节点图谱状态。继续阅读保留该来源；显式“返回知识地图”可回到原节点。安全返回只接受本地 garden 参数，不接受任意外站或可执行字符串。

浏览器后退、前进与刷新从 URL 恢复规范节点或文章。正文滚动位置在当前应用实例中按路由保存，不声称跨设备同步。关闭知识详情回到全貌，不删除知识数据。

旧专题叶子有 embeddedArticleId 时仍转换到规范阅读器。外站、下载、新窗口链接不拦截为站内文档导航。

## 滚动和响应式

工作区独占 100dvh，body 不承担文档或地图滚动。目录、阅读器、地图和详情各有明确滚动归属，面板切换不造成整页横向溢出。

地图按实际容器宽度使用三列、两列或单列，保持可读字号，不通过整体缩小密集画布适配手机。表格、公式与代码保留阅读器原有局部横向滚动。

窄屏文档侧栏与关联资料互斥；使用 inert、Escape、Tab 约束及焦点恢复，不再通过推移正文或重复 body 锁定策略实现抽屉。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| Workspace.tsx | 单一工作区、路由、抽屉、阅读位置、站内链接、返回地图 |
| model.ts | 目录 occurrence、规范文档引用、路由上下文和正文链接 |
| Explorer.tsx | 文档目录、键盘导航、全文搜索、规划分支和定位 |
| Content.tsx | 统一正文、目录索引和文档关联资料 |
| useWorkspace.ts | 主题、受限存储回退、模态焦点 |
| knowledgeIndex.ts | 全部规范节点、双向关系、区域汇总和资料来源 |
| AtlasMap.tsx | 稳定分区、可点击关联线和原生响应式布局 |
| WorkspaceGraph.tsx | 知识搜索、选择、详情、关系索引和阅读入口 |

旧 GardenCanvas、macroOverview 和 globalKnowledgeProjection 保留为历史实现，新首页不再依赖它们；不能以旧模块中的交互规则反向覆盖现行契约。

## 验收

保留原有静态数据、知识样例、Markdown、数学和图表测试。浏览器回归检查全部文档可达、旧链接、单阅读器、搜索、目录键盘、明暗主题、移动抽屉与受限存储。

新增检查：全部规范节点可搜索/归区，原始语义边无遗漏或重复，先修边不由路径伪造，资料覆盖状态不被升级；选择前后地图 DOM 和位置稳定；刷新、历史和阅读返回恢复原节点；窄屏详情可关闭并恢复导航；新地图不依赖布局 Worker。

测试矩阵覆盖 320–1920px 的多种宽度及明暗主题，另保留原有短横屏和文本放大检查。实际结果以对应提交的 GitHub Actions 为准，不据 Chromium 自动测试声称完成 iOS Safari 真机验收。
