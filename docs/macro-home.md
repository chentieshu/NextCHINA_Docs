# 宏观关系图首页与无 titlebar 工作区

## 界面约定

首页 `/` 直接显示全站宏观关系图。旧的 `?view=garden&display=graph` 链接仍进入同一全局图；已有文章深链接仍直接阅读文章。首页不是新的独立应用，侧栏、搜索、主题和阅读区域共用一个工作区。

移除顶部应用 titlebar、阅读/图谱切换栏、文档 Tab 和相关废弃样式。桌面全局操作位于左侧竖向工具栏，移动端使用底部工具栏。保留文档正文自身标题，不把应用标题栏替换成另一条标题栏。

## 同一知识网的显示层级

- 首屏：既有领域和专题节点，默认不展开右侧关系索引，给画布更多空间。
- 知识关联：既有全局知识投影，不按当前文章生成局部图。
- 搜索或展开：定位规范知识节点，查看真实关联资料；未完成的节点不伪装成已完成文章。

`macroOverviewProjection` 从既有全局数据生成领域/专题级视图，不新建第二套知识目录。概念级“建议先学”不会被提升为整个领域的先修关系。索引保留原始关系与学习路径说明。此次变更不重新核验榜单、模型或价格数据。

## 错误恢复

图谱模块或 worker 失败时，侧栏保持可用，阅读出口直接进入 `overview` 文档，不能再次跳回失败的图谱首页。无效文档链接的“打开阅读指南”也进入真实文档。

## 校验

原部署 run 36510765046 的浏览器失败是旧测试仍要求一个文档 Tab；实际界面已无 Tab。修复断言为零 Tab，同时继续断言锚点滚动、正确 hash 和单个文档阅读区，不能通过删掉用例或跳过测试来放行部署。

新增 workspace-home 浏览器测试覆盖宏观投影、首页、明暗主题、多种视口、底部工具栏、键盘搜索、关系索引、阅读往返与 worker 失败恢复。PR 校验同时构建并运行开发和生产产物的工作区测试；原 main 部署中的完整测试和 Cloudflare 部署步骤保留不变。
