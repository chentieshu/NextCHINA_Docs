# NextCHINA · Obsidian 风格数字花园

## 产品边界

全站只保留一张 AI 知识网络。点代表规范知识对象，正文在单篇阅读器中展开；不复制 Obsidian 的编辑器、多文档标签或按文章生成的局部图。44px 工具侧栏、254px 文件树、尽可能完整的点线图 / 单文档阅读区保持不变。无 titlebar、巨型首页标题、六区卡片或默认占位说明栏。

规范节点、源关系、文章注册与资料来源继续复用现有 graph 和 knowledgeIndex。界面调整不修改榜单、价格、知识事实或核验日期。目录归属、编辑关联、先学建议、专题引用和学习路线不互相冒充。

## AI 学习导航

原“知识关联”入口改为 **AI 学习导航**，回答“从哪里开始、可以先读什么、知识为什么连接”。

**学习路线**读取 graph.learningPaths，按路线展开编号知识站点。每个站点保留规范节点 ID，标注直接资料是否存在。路线只是规划阅读顺序，不新增 recommended_before 关系，资料可用不等于内容已经讲解完毕。

**概念联系**读取 knowledgeIndex.relations，分别展示“建议先学、一起理解、专题复用”。每条记录明确显示两个知识名称、关系含义和原始 reason；点击任一端到同一张全局图继续探索。支持关键词、类型筛选、逐批查看及空结果恢复，不以汇总数量代替关系说明。

知识笔记按需显示位置、简介、下级、先学与后续知识、相关概念、引用 / 被引用、阅读资料及路线。资料仍区分直接绑定、专题引用、下级资料，不用总览正文填充缺少独立讲解的概念。

## 图谱设置

设置只改变显示，不修改数据。常用视图包括全部知识、领域与专题、有资料可读。可以筛选层级、六个源知识分区、直接资料及选中节点的一跳邻居；节点即使不符合筛选也会保留，并明确告知用户，避免选中对象消失。

目录归属、概念联系、建议先学、专题引用各自有连线开关和含义说明。引用关系按 conceptRefs / hubRefs 明确字段判定，不解析编辑说明来猜测类型。视觉设置包括分区着色、标签密度、节点大小、线条粗细与可见度；交互设置包括滚轮平移 / 缩放及适配当前范围。全选、清空分区、清除筛选、恢复默认均有明确入口。

偏好使用版本化键 nextchina-graph-settings:v2。只存显示值，限制数值范围，忽略未知字段，对无效 JSON、失效分区和浏览器存储拒绝安全降级。存储失败不影响图谱或阅读。筛选不重算布局，恢复默认不删除知识。

## 点击、视口与键盘

点击节点或可见标签就地选中，不强制放大或居中。仅搜索、阅读返回与主动定位调整到目标。节点靠近边缘而面板缩小了画布时，只平移确保目标可见的最小距离，不重新布局、不改变缩放。

没有选中对象且处于全图适配模式时，打开设置或学习导航可按剩余画布自动适配；已经手动拖动 / 缩放的相机不会被面板打开重置。窗口改变尺寸时，全图模式重新适配。缓存布局必须先取得实际容器尺寸，不能按 1px 初始化后覆盖返回定位。

全视口 SVG 原生焦点框、标题提示及图谱模态黑色遮罩不作为点击反馈。画布键盘焦点由宿主承接，使用小型快捷键说明与节点局部圆环反馈，而不是取消所有焦点指示。方向键平移、+ / − 缩放、0 显示全图、Escape 清除选择。侧栏原有无障碍抽屉仍然保留。

拖动超过阈值才进入平移，双指缩放支持中点移动；pointercancel、失去捕获、窗口失焦均清理手势，不将取消或第二指抬起转换成节点点击。鼠标标签和节点均可命中，触摸有适当扩大的命中范围。

## 响应式停靠

按图谱实际容器宽度决定布局，而不是只按屏幕宽度。桌面右侧停靠单个工具 / 笔记面板；窄容器上下分区，上方保留可操作的图谱，下方独立滚动。短横屏使用并排布局，不让面板挤没画布。三个工具状态共用同一个面板，不叠加多个遮罩，不给图谱区域设置 inert 或 modal。

正文和参考型宽表格继续由原阅读器处理，本次图谱样式不会覆盖它们的阅读宽度。

## 实现边界

- networkLayout.js：规范图校验、确定性初始位置、短任务分片的布局计算和缓存。
- networkEngine.js：SVG、相机、命中、键盘 / 鼠标 / 触摸、标签避让；不修改源节点和关系。
- networkPreferences.js：版本化可选偏好与输入校验。
- ObsidianCanvas.tsx：React 生命周期适配，取消事件、布局和观察器。
- WorkspaceGraph.tsx：搜索、规范选择与阅读入口、互斥停靠面板。
- LearningNavigator.tsx / GraphSettings.tsx：面向读者的路线与联系、显示设置。
- graphWorkspace.css：图谱范围内的样式和容器响应式，不改写 Markdown 阅读器。

## 验证

PR 与正式发布均运行完整开发和实际生产构建浏览器回归。新测试覆盖源数据完整性、无视口焦点框、点击不改变缩放、路径和关系类型、偏好持久化与恢复、窄屏面板、双指与取消手势，并保留旧文档、表格、数学和图示测试。

构建产物与截图由 Actions 保存；是否通过以对应提交的实际结果为准。独立离线截图不替代真实 URL 路由测试，Chromium 回归不等于 iOS Safari 真机验证，提交 PR 不等于生产发布。
